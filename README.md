# 📖 Documentação do Desenvolvimento

## 1. O que esse código faz?
O projeto é um portfólio pessoal desenvolvido utilizando HTML, CSS e
JavaScript.
O HTML é responsável pela estrutura da página, contendo as seções de
início, sobre mim, projetos, habilidades e contato.
O CSS é responsável pelo visual do site, incluindo cores, espaçamentos,
responsividade, animações e efeitos de interação.
O JavaScript adiciona funcionalidades interativas, como a troca entre
tema claro e escuro, menu mobile e o terminal animado presente na página
inicial.

---

## 2. O que eu mudei?

Durante o desenvolvimento, comecei com uma estrutura simples de portfólio
e fui adicionando novas funcionalidades e melhorias visuais.

Entre as principais alterações estão:
- Alteração da identidade visual do site.
- Criação de um tema baseado em tons escuros e vermelho.
- Criação de efeitos ao passar o mouse sobre elementos.
- Criação de um terminal interativo na página inicial.
- Implementação de animação de digitação.
- Criação de uma barra de progresso no terminal.
- Adição de alternância entre tema claro e escuro.
- Adição de SQL e Banco de Dados na seção de tecnologias estudadas.
- Melhoria da responsividade para celulares e tablets.
- Organização das habilidades utilizando CSS Grid.

---

## 3. Por que eu fiz essas mudanças?
As alterações foram realizadas para deixar o portfólio mais moderno,
interativo e representativo das minhas habilidades.
O terminal interativo foi criado para tornar a primeira seção do site
mais dinâmica e apresentar de forma diferente as tecnologias que estou
estudando.
Também optei por utilizar uma identidade visual escura com detalhes
vermelhos para criar uma aparência mais moderna e tecnológica.
A responsividade foi trabalhada para que o site possa ser acessado
corretamente em diferentes tamanhos de tela.

---

## 4. Como utilizei Inteligência Artificial?

Durante o desenvolvimento do projeto utilizei Inteligência Artificial
como ferramenta de apoio.

A IA foi utilizada principalmente para:
- Sugerir melhorias no código.
- Auxiliar na criação de animações em CSS.
- Ajudar na implementação do terminal interativo.
- Explicar conceitos de HTML, CSS e JavaScript.
- Identificar possíveis erros no código.
- Sugerir melhorias de organização e responsividade.
- Auxiliar na documentação do projeto.

Apesar do uso da IA como ferramenta de apoio, as alterações foram analisadas,
testadas e adaptadas de acordo com as necessidades do meu projeto.

---

## 5. O que eu aprendi?

Durante o desenvolvimento deste projeto, pude praticar conceitos de:
- Estruturação de páginas utilizando HTML.
- Estilização utilizando CSS.

# 🚀 Publicação do projeto
Para publicar o projeto na internet utilizei o **GitHub Pages**.
Primeiramente, o código foi enviado para um repositório no GitHub utilizando
Git.
Depois, o GitHub Pages foi configurado para utilizar os arquivos do
repositório como uma página web.
Após a publicação, o projeto passou a estar disponível através de um
endereço público na internet.
