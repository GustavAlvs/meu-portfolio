# Portfólio Web — GitHub Pages

## Arquivos
- `index.html` — estrutura da página
- `style.css` — visual e responsividade
- `script.js` — menu mobile, modo escuro/claro e ano automático

## Antes de publicar
1. Troque `Seu Nome` pelo seu nome.
2. Troque o e-mail.
3. Coloque seu link real do GitHub.
4. Se quiser, substitua os projetos de exemplo pelos seus.

## Publicação
Crie um repositório no GitHub, envie os três arquivos e ative:
Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)`.
